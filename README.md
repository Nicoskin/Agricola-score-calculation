# Счётный лист Агриколы

Одностраничный сайт для подсчёта победных очков в настольной игре «Агрикола» (издание 2016 года) — вместо карандаша и листочка.

- подсчёт по категориям: сначала поля у всех игроков, потом пастбища и т. д.;
- табло очков в стиле игрового поля, монеты очков, подсказки «Как считать» со схемами;
- особые улучшения с автоматическим бонусом мастерских;
- итоги партии по блокам, до 6 игроков.

Сайт — это один файл `index.html` без сборки и зависимостей (шрифты подгружаются с Google Fonts).

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `agricola-score`.
2. Отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/agricola-score.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/agricola-score/`.

## Что и где сохраняется

| Что | Где | Сколько хранится |
|---|---|---|
| Имена и цвета игроков | куки `agricola_players` | 400 дней, срок продлевается при каждом заходе |
| Очки текущей партии | `localStorage` браузера | пока не нажата «Новая партия» |

Данные никуда не отправляются и живут только в браузере конкретного устройства.

**iPhone / Safari:** Safari стирает куки и `localStorage`, записанные сайтом, если на сайт не заходили 7 дней. Чтобы настройки жили дольше, откройте сайт в Safari → «Поделиться» → **«На экран „Домой“»** и запускайте его оттуда — для такого ярлыка ограничение не действует.

## Локальный запуск

Просто откройте `index.html` в браузере. Куки при открытии файла с диска не работают, но `localStorage` работает.
