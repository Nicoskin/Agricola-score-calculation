# Счётный лист Агриколы

Одностраничный сайт для подсчёта победных очков в настольной игре «Агрикола» (издание 2016 года) — вместо карандаша и листочка.

- подсчёт по категориям: сначала поля у всех игроков, потом пастбища и т. д.;
- табло очков в стиле игрового поля, монеты очков, подсказки «Как считать» со схемами;
- особые улучшения с автоматическим бонусом мастерских;
- итоги партии по блокам, до 6 игроков;
- выгрузка результатов: картинка PNG (с датой и очками всех игроков), текст `.txt` или `JSON`;
- история партий: каждая партия сохраняется с датой, счётом и разбором по категориям;
- работает без интернета и ставится на телефон как приложение.

Сборки и зависимостей нет: сайт — это `index.html`, `sw.js`, `manifest.webmanifest` и иконки.

## Офлайн и установка на телефон

При первом заходе с интернетом service worker (`sw.js`) складывает в кэш страницу, иконки и шрифты Google Fonts. Дальше сайт открывается и считает полностью без сети — как раз для стола, где нет вайфая.

Установка:

- **Android, Chrome:** в шапке сайта появится кнопка **«Установить»**. Либо меню браузера → «Установить приложение».
- **iPhone, Safari:** «Поделиться» → **«На экран „Домой“»**.
- **Компьютер, Chrome или Edge:** значок установки в адресной строке.

Установленный ярлык запускается на весь экран, без адресной строки. Для iPhone это ещё и важно для сохранности данных: Safari стирает куки и `localStorage` обычного сайта, если на него не заходили 7 дней, а для установленного приложения это ограничение не действует.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `Agricola-score-calculation`.
2. Отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/Agricola-score-calculation.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/Agricola-score-calculation/`.

**Важно при обновлении сайта:** поменяйте строку `const VERSION = 'v1';` в начале `sw.js` (v2, v3 и т. д.). Тогда у всех, кто уже заходил, старый кэш удалится и подхватится новая версия. Страница и так запрашивается из сети в первую очередь, но смена версии гарантирует обновление остальных файлов.

## Что и где сохраняется

| Что | Где | Сколько хранится |
|---|---|---|
| Имена и цвета игроков | куки `agricola_players` | 400 дней, срок продлевается при каждом заходе |
| Очки текущей партии | `localStorage` браузера | пока не нажата «Новая партия» |
| История партий | `localStorage` браузера | до нажатия «Очистить историю», хранятся последние 100 партий |
| Галочка «показывать количество» | `localStorage` браузера | до очистки данных сайта |
| Страница, иконки, шрифты | кэш service worker | до смены версии в `sw.js` |

Данные никуда не отправляются и живут только в браузере конкретного устройства.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | весь сайт: разметка, стили, логика |
| `sw.js` | service worker, офлайн-режим |
| `manifest.webmanifest` | описание приложения для установки |
| `icon.svg`, `icon-maskable.svg` | исходники иконок |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | иконки приложения |
| `favicon.svg` | значок во вкладке браузера |
| `.nojekyll` | чтобы GitHub Pages не обрабатывал сайт своим генератором |

## Локальный запуск

Файл `index.html` можно просто открыть в браузере, но офлайн-режим и куки при этом не работают: браузеры разрешают их только по `http`. Поэтому для проверки поднимите локальный сервер:

```bash
python -m http.server 8765
```

и откройте `http://127.0.0.1:8765/`.
